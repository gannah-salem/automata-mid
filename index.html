Theory of Automata and Formal Languages (AI 412)

📌 أسئلة مقالية ونظرية محلولة من الكويزات للمراجعة

1. مقارنة شاملة: DFA vs NFA vs ε-NFA (من Quiz 2)
1) Formal Definition:
All are 5-tuple: (Q, Σ, δ, q0, F).
• DFA: δ: Q × Σ → Q (deterministic, single state output).
• NFA: δ: Q × Σ → P(Q) (non-deterministic, power set output).
• ε-NFA: δ: Q × (Σ ∪ {ε}) → P(Q) (adds ε-transitions).
All three recognize the exact same class of languages (Regular Languages).

2) Design vs Execution:
• NFA / ε-NFA: Easier/intuitive to design, fewer states, but execution is slower.
• DFA: Optimal for runtime execution O(n) (used in compiler lexical analyzers), but can require exponential number of states.

3) Conversion:
Subset construction converts NFA to DFA. For ε-NFA, calculate ε-closure first.

4) Applications:
DFA used in performance-critical lexical scanners. NFAs used in regex engines and modeling concurrent systems.
2. إزالة الحالات غير القابلة للوصول Remove Unreachable States (من Quiz 3)
Algorithm:
1. Start with Q0 = {Initial State A}.
2. Compute reachable states on inputs 0 and 1: Q1 = {A} ∪ δ(A,0) ∪ δ(A,1).
3. Repeat until Qi = Qi-1.
4. Any states not present in the final reachable set (such as state C and D) are deleted, producing the minimal connected automaton.
